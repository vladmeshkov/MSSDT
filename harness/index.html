Thought → Action → Observation

Сердцебиение агента — обычный цикл

пока задача не решена: промпт = собрать(контекст) ответ = llm(промпт) если вызовов нет: вернуть ответ # финал результаты = выполнить(вызовы) контекст += результаты

Схема, не реальный код. Anthropic называет свой runtime «тупым циклом»: интеллект живёт в модели.

Когда цикл заканчиваетсяответ без вызовов, лимит ходов, бюджет токенов, tripwire, прерывание пользователем, safety refusal

Как это устроено

Инструмент описан схемой: имя, описание, типы параметров. Схема попадает в контекст, и модель знает, что ей доступно.

  • регистрация и проверка схем
  • извлечение аргументов
  • изолированное выполнение
  • результат — в виде наблюдения

Claude Code

Шесть категорий инструментов:

  • файловые операции
  • поиск
  • выполнение
  • веб-доступ
  • анализ кода
  • запуск субагентов

Agents SDK OpenAI

Три вида инструментов:

  • @function_tool — свои функции
  • hosted tools: WebSearch, CodeInterpreter, FileSearch
  • инструменты MCP

Парсинг вывода

Современные harness’ы опираются на native tool calling: модель возвращает структурированные tool_calls, а не свободный текст. Вызовы есть — выполняем и продолжаем цикл; нет — это финальный ответ.

Context rot

Контекст — дефицитный ресурс

30%+

на столько падает качество, когда важное оказывается в середине окна.

Исследование Chroma, подтверждённое «Lost in the Middle» (Stanford). Даже окна в миллион токенов теряют в следовании инструкциям. Поэтому важное кладут в начало и конец промпта.

  1. 1
    Compactionсуммаризация истории у лимита; Claude Code сохраняет архитектурные решения и нерешённые баги
  2. 2
    Observation maskingстарые выводы инструментов скрыты, вызовы видны (JetBrains Junie)
  3. 3
    Just-in-time retrievalлёгкие идентификаторы, данные грузятся по ходу: grep, glob, head, tail вместо целых файлов
  4. 4
    Делегирование субагентамисследуют широко, возвращают саммари на 1000–2000 токенов

Что такое harness?Метафора
Строительные леса

Леса убирают, когда здание готово

По мере улучшения моделей сложность харнесса должна снижаться.

  • Manus перестраивали пять раз за шесть месяцев, каждый раз убирая сложность: хитрые определения инструментов стали общим shell, «управляющие агенты» — простыми handoff’ами.
  • Ко-эволюция: модели дообучают со своими харнессами. Смена реализации инструментов может ухудшить результат.

Тест на будущее: качество растёт с более мощной моделью, а сложность харнесса — нет. Значит, дизайн верный.

Что выбирает каждый архитектор

1
Один агент или несколькоСначала один. Делить, когда больше ~10 пересекающихся инструментов.
2
ReAct или plan-and-executeReAct гибок, но дороже на шаг. LLMCompiler: ускорение в 3,6 раза.

4
Цикл проверкиВычислительная (тесты) или inferential (LLM-судья, с задержкой).
5
Права и безопасностьPermissive: быстро, но рискованно. Restrictive: безопасно, но медленно.
6
Набор инструментовБольше — часто хуже. Vercel убрал 80% инструментов v0; Claude Code экономит 95% контекста.
7
Толщина harness’аAnthropic ставит на тонкий и убирает шаги, когда модель их усвоила.
Что такое harness?Взгляд маркетолога
Harness — это и есть продукт

Модель — товар, harness — продукт

1

Модели доступны всем

GPT, Claude и Gemini подключает через API любой разработчик.

2

Отличие уходит в обвязку

На одинаковых моделях продукты работают по-разному: в TerminalBench смена одного harness’а двигала агентов на 20+ позиций.

3

Это не коммодити

Контекст как дефицит, проверка, память без галлюцинаций, ставка на толщину — слой, где живёт сложный инжиниринг.

Клиенту продают не «доступ к ИИ», а выполненную задачу. И эту задачу делает harness.
