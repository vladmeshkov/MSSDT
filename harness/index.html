За что вы платите на самом деле

Память

Помнит ли он вас между днями?

Пример: Claude Code хранит заметки о вашем проекте в отдельных файлах и читает их при каждом запуске.

Проверка

Проверяет ли он себя, прежде чем сдать?

Пример: прогоняет тесты, смотрит на скриншот. С самопроверкой качество растёт в 2–3 раза.

Права

Спросит ли он, прежде чем что-то удалить?

Пример: в Claude Code около 40 действий проверяются отдельно, рискованные — с вашего согласия.

Доведение до конца

Остановится ли он на полпути?

Пример: агент повторяет «подумал → сделал → проверил», пока задача не решена.

Итоги
1

Модель — товар. Harness — продукт.

Модели доступны всем; отличие продукта живёт в программе вокруг модели.

2

Harness — это память, проверка, права и доведение до конца.

Не магия, а свойства, которые можно проверить и сравнить.

3

Продавайте и выбирайте по этим свойствам, а не по названию модели.
